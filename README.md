MyDocs — GitHub Pages deployment

Upload the contents of this folder directly to the root of your GitHub Pages repository (the same level as index.html). All app and icon files are kept at the root; no enclosing project folder or nested ZIP is needed.

If the app was previously installed, refresh the site to pick up the updated service-worker cache. Existing documents are stored in the browser, so do not clear website data unless you have a backup.


Latest update: modern Google Docs-style text color palette, document-options button on the right, and optional automatic light/dark mode following the device appearance setting. The project remains flat for GitHub Pages.
